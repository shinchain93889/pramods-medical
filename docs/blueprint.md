# **App Name**: Pramod Medical Store

## Core Features:

- Product Catalog & Search: Displays a hero section, categories (Tablets, Syrups, First Aid, Health Supplements) and featured products on the homepage. Provides a dedicated products page with a grid layout, search bar, and category filters for browsing all medicines, with each product showing image, name, price, and 'Add to Cart' button.
- Shopping Cart System: Allows users to add products to a shopping cart, view the total price of items, and remove items as needed before checkout.
- Prescription Upload: A dedicated page with a form allowing users to upload a prescription image along with their name and phone number for processing, including server-side handling of the uploaded file.
- Contact & Location: Includes a contact form with EmailJS integration for sending messages, displays shop details (address, phone, email), features a Google Map for shop location, and provides a WhatsApp contact button for direct communication.
- User Authentication: A basic login page with email and password fields, including simple client-side validation to allow returning customers to access their account.
- Responsive User Interface: Ensures the entire website adapts gracefully to various screen sizes (mobile, tablet, desktop) using modern UI components like cards, buttons, and icons, featuring smooth animations for transitions and toast messages for user feedback on actions.
- AI-Powered Product Suggestion Tool: Provides contextual product recommendations to users, acting as an intelligent tool that suggests complementary items based on frequently purchased products or popular combinations within the store's inventory.

## Style Guidelines:

- Primary color: A professional and trustworthy deep blue (#1D8BB2) for branding elements and calls to action.
- Background color: A very subtle, almost white, cool blue-tinted shade (#F7FAFB) to maintain a clean and pristine medical aesthetic.
- Accent color: A health-focused and calm medical green (#228B22) to highlight important information and balance the primary blue.
- Headline and body font: 'Inter' (sans-serif), chosen for its modern, neutral, and highly readable qualities, fitting a professional medical context.
- Utilize a consistent set of clean, line-art style icons. Icons should be clear, easily recognizable, and relevant to medical themes, health, and e-commerce functionalities (e.g., cart, upload, user profile).
- The design will emphasize responsiveness, employing a mobile-first approach. Product displays will use grid layouts with distinct cards, and navigation will be intuitive. Information will be presented in a well-organized, spacious manner to ensure readability and ease of use on all devices.
- Incorporate subtle and smooth animations to enhance user experience, such as gentle hover effects on buttons and cards, smooth transitions for page loads or state changes, and concise toast notifications for feedback on form submissions or cart updates.
